# Authored as the counter-case of the identity rule: the same declaration twice,
# and only the position of one of them says what it is.

# FleetTag and Berth are the same declaration — a record around one value — so the shape of

# never by the second, so the first is settled and the second keeps both readings.
#
# Leaving Berth undecided is the point. The aggregate holds it, and calling it a value on
# that ground would settle the duel by position, which is evidence of nothing.
