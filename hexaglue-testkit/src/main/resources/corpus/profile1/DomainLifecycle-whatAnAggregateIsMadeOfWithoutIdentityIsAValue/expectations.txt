# DomainLifecycle-whatAnAggregateIsMadeOfWithoutIdentityIsAValue
#
# Authored for composition. Once a way out has established the aggregate, what
# the aggregate holds is part of it, whatever the parts are called.

# Hull is held through a collection and Manifest through a plain field: holding many of a
# part composes as much as holding one. Neither carries an identity of its own, so both read
# as values.
#
# Hull is mutable, with a method that changes it, and it is a value all the same. What the
# type is and what is wrong with it are two questions: refusing to identify a badly written
# value object would leave the audit nothing to report on.
