# Authored for the other half of composition: the part that can be told apart
# from another one holding the same attributes.

# Hull and Manifest sit at the same place in the composition, and only one of them carries
# something the analysis reads as an identity. That is the whole difference between an entity
# and a value inside an aggregate, and it is why the reading runs down one level further:
# Manifest is read as a part of Hull once Hull is an entity.
#
# HullTag is declared, which is deliberate. A field that merely looks like an identity is the
# duel this wave refuses to settle by position, so the entity reading needs an identity some
# other rule has already established.
